# PQL 자동화 - Product Sense

## 미션

PQL(Product Qualified Lead) 리드 엑셀 파일을 자동으로 Google Sheets에 가져와 필터링/가공하여, 세일즈팀이 즉시 아웃바운드 콜에 활용할 수 있는 clean 리드 리스트를 생성한다.

## 해결하는 문제

PQL 리드 데이터가 엑셀 파일로 제공되는데, 이 파일에는 이미 서비스를 사용 중이거나, 주문수가 적거나, 연락처가 없는 대상이 다수 포함되어 있다. 세일즈팀은 매번 수동으로 필터링하고 컬럼을 재배치해야 했다.

## 사용자

| 사용자 | 역할 | 핵심 니즈 |
|--------|------|-----------|
| 세일즈 SDR | 아웃바운드 콜, 리드 발굴 | 바로 전화할 수 있는 깨끗한 리드 리스트 (이름, 전화번호, 서비스 라벨) |
| 세일즈 매니저 | 리드 할당, 캠페인 관리 | 플랫폼별, 서비스별 리드 규모 파악 |

## 핵심 가치

1. **즉시 사용 가능한 리드 리스트** -- 필터링(주문수 100 이상, 기존 서비스 미사용 등) + 가공(전화번호 포맷, 서비스 라벨)을 자동으로 수행하여 SDR이 바로 콜할 수 있다.
2. **중요 정보 우선 배치** -- shop_name, shop_id, 플랫폼, 주문수, 서비스 라벨, 담당자 정보가 앞쪽 컬럼에 배치되어 한눈에 파악 가능하다.
3. **원클릭 실행** -- 메뉴에서 "최신 파일 가져오기 & 가공 실행" 하나로 전체 프로세스를 완료한다.

## 제품 원칙

- **필터링 기준은 비즈니스 룰이다**: 주문수 100 미만 제외, 알파업셀 라이브 제외 등은 세일즈팀의 아웃바운드 대상 선정 기준이다. 변경 시 세일즈팀과 합의 필요.
- **데이터 손실 없이 가공**: raw 시트에 원본을 보존하고, clean_{timestamp} 시트를 별도 생성한다. 이전 결과도 유지된다.
- **성능 > 기능**: API 호출을 최소화(3회)하여 대용량 데이터에서도 빠르게 동작한다.

## 성공 지표

| 지표 | 현재 값 | 목표 |
|------|---------|------|
| 수동 필터링 시간 절감 | ~30분/회 -> ~1분 | 유지 |
| Sheets API 호출 수 | 3회 | 유지 |
| 리드 필터링 정확도 | 비즈니스 룰 100% 반영 | 100% 유지 |
| clean 시트 생성 소요 시간 | 수초 | 유지 |

## 경쟁 대안

| 대안 | 장점 | 단점 | 선택하지 않은 이유 |
|------|------|------|---------------------|
| 수동 스프레드시트 필터링 | 설정 불필요 | 매번 30분+, 실수 가능 | 반복 비용 과다 |
| Google Sheets FILTER/QUERY 수식 | 실시간 갱신 | 복잡한 가공(전화번호 포맷, 라벨링) 어려움 | 서비스 라벨링 로직이 수식으로는 복잡 |
| Python 스크립트 | 강력한 데이터 처리 | 별도 실행 환경 필요, 비개발자 사용 어려움 | SDR이 직접 실행해야 하므로 Apps Script가 적합 |
| 현재 방식 (Apps Script) | Google Sheets 내장, 원클릭 | Apps Script 제약 | 채택 |
